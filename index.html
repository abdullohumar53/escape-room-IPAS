Tentang Gim Edukatif

MISTERI SISTEM PENCERNAAN — ESCAPE ROOM IPAS

Gim ini dirancang khusus sesuai pembelajaran IPAS Fase C Kelas 5 SD (Kurikulum Merdeka). Gim menggabungkan strategi Escape Room interaktif untuk menguji pemahaman organ pencernaan, urutan makanan, fungsi organ, gejala penyakit pencernaan, serta kemampuan analisis dan ketelitian siswa.

Mata Pelajaran: Ilmu Pengetahuan Alam dan Sosial (IPAS)
Sasaran Usia: 10 – 11 Tahun (Kelas V SD)
Pengembangan UI/UX: Adaptive Responsive Educational Web App
Penyimpanan Data: Standalone browser LocalStorage API
